# 多语言版本说明（i18n / Internationalization）

> **制作者**：精卫服务队 于海峰 狮兄 ｜ **版本** v1.0.0 ｜ 2025-09-28
> 本目录提供 `lions-clubs-constitution` 技能的**多语言参考译本**，覆盖港澳台、日韩、东南亚、中亚、欧洲、非洲、美洲、俄罗斯等区域。

## 一、重要声明（务必阅读）

1. **唯一权威源**：本技能所有内容的**权威来源是中文官方文件**（见 `references/manifest.md`）。多语文件仅为**方便非中文会员理解而由本技能编制的参考译文**，**非中国狮子联会官方译本**。
2. **法律效力**：如译文与中文官方原件不一致，以**中文官方原件为准**。正式会务、合规判断、对外文书请以中文原文或联会官方发布版本为准。
3. **语言自动选择**：各类 Agent 收到请求时，应先识别用户语言，再到 `i18n/<语言代码>/summary.md` 读取对应参考卡；若语言不在覆盖表中，回退中文并提示"以中文官方原文为准"。

## 三、每份 `summary.md` 的统一结构（便于 Agent 解析）

1. 机构身份（名称/英文/简称/宗旨/主管/住所/国际归属）
2. 会员（条件/权利/义务/自动退会/除名）
3. 会费（标准/时限/年度周期）——数字全球一致
4. 会员行为红线（含第八条禁止商用标识）
5. 服务队组织与运作（设立/队长团队/会议）
6. 视觉形象核心（标志/标准色/禁用/商用禁令）
7. 免责声明（以中文官方原件为准）

## 四、如何为技能增加新语言

1. 在 `i18n/` 下新建 `<语言代码>/` 目录与 `summary.md`；
2. 复制上述 7 节结构，翻译**已核实的中文核心事实**（数字不得改动）；
3. 在本文档"覆盖矩阵"追加一行；
4. 在 `SKILL.md` 与 `README.md` 的语言列表同步更新。

> 中文官方文件更新时，应同步复核各语言 `summary.md` 并递增技能版本号。
