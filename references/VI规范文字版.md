## 二、核心规范（文字速查）

### 2.1 标志制图（手册 A02）

- 联会标志以国际狮子会标志为基础设计，**外形为其等比放大**。
- 以国际狮子会左右狮鼻尖为直径画标志同心圆，作为中文"中国狮子联会"底边。
- 以标志中 L 的上边宽为标准尺寸 **"2a"**：中文字高为 **2a**，中文字体左右两边以 L 的延伸线对齐。
- 英文字高为 **a**，和中文字体居中对齐；英文左右两边与 L 的水平延伸线对齐。
- 标志最外沿顶部距离中文字外沿边为 **1.5a**。

### 2.2 标准组合（手册 A05–A13）

- **横式组合**：标志在左，中文"中国狮子联会"+ 英文"CHINA COUNCIL OF LIONS CLUBS"在右（手册 A06）。
- **上下组合**：标志在上，名称在下；须备**彩色稿、墨稿（黑色单色）、反白稿**三种版本（手册 A11）。
- **竖式组合**：标志在上，名称竖排在下（手册 A13）。
- 组合比例关系以手册网格制图为准，**不得自行调整标志与文字的大小比例、间距**。

### 2.3 安全距离与最小尺寸（手册 A14）

- 标志四周须保留**安全距离**（以标志中 L 字高为度量单位，见 A14 网格图），安全距离内不得出现其他图文。
- 标志（含名称组合）**最小尺寸：高度 1cm**（印刷）；小于该尺寸不得使用完整组合，应改用单独标志或不用。

### 2.6 背景明度规范（手册 A18，横式/上下式组合均适用）

| 背景墨色明度 | 彩色版标志处理 |
| --- | --- |
| **0%–20%** | 标志呈标准正确状态使用 |
| **30%–40%** | **禁止使用**（易与背景混淆） |
| **50%–100%** | 可用，但标志中的标准文字组合须呈**反白**状态 |

### 2.7 底色应用矩阵（手册 A20）

标志组合可置于**蓝、黄、红、黑、金、银**六种底色上；组合用字分**白字/黑字、白、黑、金、银**五档。手册以矩阵给出**允许与禁止（划线格）组合**，常见结论：

- 蓝底 → 标准色标志 + 白字可用；黑字组合禁止。
- 黄底 → 标准色 + 黑字可用；白字组合禁止（对比不足）。
- 红底 → 墨稿（黑）标志 + 白/黑字可用；标准色标志（红环）禁止。
- 黑底 → 彩色标志 + 白字可用；银色标志视对比可用。
- 金底 / 银底 → 墨稿黑标志可用；金色标志禁用于金底、银底同理。

> 执行时以 A20 矩阵图为准；未列入矩阵的底色，按 A18 明度规范判断。

### 2.8 禁止使用的错误形式（手册 A21，逐项审查清单）

1. 禁止将标志**不按比例拉伸压缩**。
2. 禁止以**扭曲与变形**表现标志。
3. 禁止以**线条、投影或任何特效**表现标志。
4. 禁止标志与其背景底色使用**违反明度规范**。
5. 禁止**改变标志中文字部分的色彩**。
6. 禁止将标志中**嵌入任意纹理、图案或图像**。
7. 禁止**改变标志中图形部分的色彩**。
8. 禁止标志应用在**对比强烈的背景色**上。
9. 禁止将标志直接应用于**任何混乱、刺激的背景**上。
10. 禁止将标志直接应用于**与标准色近似的图片**上。

**其他禁止（A21 右侧文字）**：

- 扭曲比例或形状；
- 改变字体、字号或其位置关系；
- 在标志上绘画或添加字符；
- 在标志周围添加轮廓、黑体、亮点或形状以更改标志形态；
- 向标志添加文字，或在标题、名称或句子里使用标志；
- 和其他机构标志结合在一起（除非获得必要的许可后，依照本手册相关规范执行）。

### 2.9 代表处应用（手册 B）

- 各代表处（北京、深圳、广东、大连、青岛、浙江、沈阳、哈尔滨、四川、海南、云南、江苏、吉林等）标识组合以手册 B 对应页为准。
- 服务队物料应**先对照所在代表处版本**，再套用手册 A 的通用规范。
- 海南（DISTRICT 391）、云南（392）、江苏（393）、吉林（394）等含国际区号组合，使用时核对区号与英文名拼写。
