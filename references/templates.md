# 官方文案模板（依据联会基本法整理）

> 以下模板为依据《中国狮子联会章程》《工作规则》《财务管理制度》《会员行为准则》整理的常用文案骨架。使用时请结合服务队实际情况填写，涉及数字与程序须对照 `references/` 原文核实。

## 1. 服务队全体会员会议通知（依据《工作规则》第 86 条）

```
中国狮子联会【代表处名称】【服务队全称】
关于召开【年度】全体会员会议的通知

各位会员：

根据《中国狮子联会工作规则》第八十六条关于服务队全体会员会议应于每年3月至4月中旬召开的规定，经队长团队研究，定于【日期】【时间】在【地点】召开服务队【年度】全体会员会议。现将有关事项通知如下：

一、会议议程
（一）审议服务队【年度】工作报告；
（二）审议服务队【年度】财务报告；
（三）审议服务队下一年度工作计划及财务预算；
（四）推举服务队下一年度队长团队；
（五）其他事项。

二、参会人员：服务队全体会员。

三、有关要求：请准时参会；因故不能出席的，请提前向秘书请假。

【服务队全称】队长团队
【日期】
```

## 2. 入会申请（依据《章程》第十七、十八条）

```
中国狮子联会入会申请书

本人【姓名】，【性别】，【出生年月】出生，系【职业/单位】【职务】，自愿申请加入中国狮子联会【代表处/单位会员】【服务队名称】。

本人郑重承诺：
一、年满二十周岁，系中华人民共和国公民；
二、拥护《中国狮子联会章程》，遵守联会各项规章制度及《中国狮子联会会员行为准则》；
三、自愿加入，有志于服务社会、投身社会公益事业；
四、按时足额缴纳会费（入会费及年度会费标准按《中国狮子联会会费收取办法》执行）；
五、履行会员义务，维护联会声誉。

申请人：【签名】
【日期】
```

## 3. 转队申请（依据《工作规则》第十九条）

```
转队申请书

本人【姓名】系【原服务队全称】会员，因【原因】，申请转入【目标服务队全称】。本人已知悉并承诺按《中国狮子联会会费收取办法》缴纳转队费，配合办理会籍转移手续。

申请人：【签名】
【日期】

原服务队队长团队意见：【签字/日期】
转入服务队队长团队意见：【签字/日期】
```

## 4. 活动方案骨架（合规要点内嵌）

```
【活动名称】方案

一、活动背景与宗旨（对照《章程》第三条：正己助人，服务社会）
二、组织架构：主办/承办/指导单位；项目负责人及分工
三、时间地点与对象
四、活动流程
五、经费预算与来源
    —— 须列明预算明细；资金使用符合《财务管理制度》第七章支出管理、第十章票据管理
六、对外宣传安排
    —— 标识使用对照 VI 手册；不得将联会标识用于商业用途（《会员行为准则》第八条）
七、风险评估与合规自查
    —— 募捐行为合法性自查（《会员行为准则》第四条）
    —— 受益人权益与隐私保护（《会员行为准则》第六条）
八、报批：按所在代表处要求报批，留存审批记录
```

## 5. 财务公开/报销说明要点（依据《财务管理制度》）

```
【项目/活动】财务说明

一、收入：来源、金额、入账凭证（票据依《财务管理制度》第十章管理）
二、支出：明细、金额、审批人、票据
三、结余处理：按制度转入规定账户/用途
四、公开方式：向全体会员公开，接受监督（《会费收取办法》第十条精神）
```

## 6. 违规行为处理建议报告（依据《会员行为准则》第十四、十五条）

```
关于对会员【姓名】违规行为处理的建议报告

【服务队/代表处/单位会员全称】：
经查，会员【姓名】于【时间】存在以下违反《中国狮子联会会员行为准则》的行为：
【事实与依据条款，如：违反第八条，擅自将联会标识用于商业宣传】

根据《中国狮子联会会员行为准则》第十四条、第十五条，建议给予【诫勉谈话/书面警告/免职/劝退/除名】处理。

报告单位：【队长团队/代表处办公会议/单位会员理事会】
【日期】
```
