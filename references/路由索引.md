## 快速检索命令

```bash
# 在 references 中按关键词定位（输出 文件|页码|条款号|命中行）
python3 scripts/search_clauses.py 会费
python3 scripts/search_clauses.py 服务队 工作规则
python3 scripts/search_clauses.py 标识 会员行为准则
```

> 注：会费办法、VI 手册 A 部分无/少文本层，其原文以 `references/assets/会费办法/` 与 `assets/vis/` 图示为准，检索不到时直接调图核对。
